Format Guide

  • Q: question text starts each question
  • * choice marks a correct choice
  • choice or - choice is an incorrect choice
  • = answer specifies an accepted answer for fill-in-the-blank
  • Tags on Q: [select_all], [partial], [fill_blank], [typos]
  • Points: 2 (defaults to 1 point)
  • Explanation: text shown after student submits
  • Separate questions with an empty blank line
